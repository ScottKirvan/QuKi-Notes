## GitHubDHC-theme.css

Unmodified copy of `theme.css` from [ScottKirvan/GitHubDHC](https://github.com/ScottKirvan/GitHubDHC) (MIT), an Obsidian theme implementing GitHub's Primer Dark High Contrast colour scheme. It is the style reference for QuKi Notes' default theme: by default the app should look like this theme.
