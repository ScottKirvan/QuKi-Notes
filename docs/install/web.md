
# Installing QuKi Notes (Web App)

In addition to running as an app, QuKi Notes can run entirely in your browser, or installed as a web app — no account, no sign-up, nothing to download from a store. You can use it in a regular browser tab, or install it as a web app on your desktop or phone for quicker access.

## Before you start

QuKi Notes for web stores everything **inside your browser**, on your device only:

- There's no account and nothing syncs between devices or browsers.
- Clearing the site's browsing data (or uninstalling the browser) deletes your QuKis.
- Use **Settings → Export** regularly to save a backup you can keep elsewhere — see [Back up your QuKis](#back-up-your-qukis) below.

For the best experience, use a recent version of **Chrome, Edge, or another Chromium-based browser**. Other browsers may work but aren't the primary target.

## Install as an app

Installing adds QuKi Notes to your desktop or home screen and runs it in its own window, without browser tabs or address bars.

### Desktop (Chrome or Edge)

1. Go to **https://QuKiNotes.ScottKirvan.com**.
2. Click the **install icon** in the address bar (it looks like a small monitor with a down arrow), or open the browser menu and choose **Install QuKi Notes**.
3. Confirm the install prompt. QuKi Notes now opens from your desktop, Start menu, or Applications folder like any other app.

### Android (Chrome)

1. Go to **https://QuKiNotes.ScottKirvan.com**.
2. Tap the **⋮** menu in the top right.
3. Tap **Install app** (or **Add to Home screen**).
4. Confirm. QuKi Notes now appears as an icon on your home screen.

### iPhone / iPad (Safari)

1. Go to **https://QuKiNotes.ScottKirvan.com**.
2. Tap the **Share** icon.
3. Tap **Add to Home Screen**.
4. Confirm. QuKi Notes now appears as an icon on your home screen.

> Browser support for offline storage varies more on iOS than on Android or desktop. If you rely on QuKi Notes daily on iPhone or iPad, export a backup a little more often.

## Just use it in a browser tab

No install required — go to **https://QuKiNotes.ScottKirvan.com** and start typing. Your QuKis are saved automatically as you type. Bookmark the page for quick access later.

## Back up your QuKis

Since web storage lives only in this browser on this device, back up regularly:

1. Open **Settings**.
2. Tap **Export**.
3. Your browser downloads a single archive containing every QuKi, including Trash and any pasted images.
