  # QuKi Notes for iOS & MacOS

  QuKi Notes _isn't_ currently available, natively for iOS, iPad, or MacOS, but you can [access, use, and install it as a web app](web.md) on these platforms.

  All notes are still private, save locally on your system, and can be manually exported out of the browser environment, but you may not be able to directly access them on your filesystem, and they will be removed if you clear your browser's local storage.

If you're a iOS, iPad, or Mac user, and really want to see QuKi Notes on your devices, please let us know, 
consider supporting the project, and stay tuned for native versions in the future.
