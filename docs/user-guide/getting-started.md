# Getting Started

## What is QuKi-Notes?

QuKi-Notes is a capture-and-dispatch app. You open it, type a note (a QuKi), and send it somewhere — a clipboard paste, an Android share sheet, or any transport you enable. There is no vault, no folder structure, no organisation ritual. Capture is the point; dispatch is the exit.

## Platforms

| Platform | Status |
|---|---|
| Android | Primary — fully supported |
| Windows | Supported |
| Linux | Supported |
| iOS / macOS | Not yet available |

## Installation

Download the latest release from [GitHub Releases](https://github.com/ScottKirvan/QuKi-Notes/releases).

- **Android**: install the `.apk` directly, or sideload via ADB.
- **Windows**: extract and run the bundled `.exe`.
- **Linux**: extract and run the bundled binary.

## First launch

The app opens directly into the editor — blank, cursor ready. No onboarding, no sign-in. Start typing.

Your QuKi saves automatically as you type. When you are done, send it somewhere or leave it — it will be there when you return.

## Navigation at a glance

The editor is home. It does not have a back button.

- **QuKis icon** (top left in the editor) — opens your QuKis list
- **Menu** (top right, three-line icon) — Send..., QuKis, Settings

From the QuKis list:

- **+ icon** (top right) — new QuKi
- **Settings icon** (top right) — Settings
