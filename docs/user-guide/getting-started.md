# Getting Started

## What is QuKi Notes?

QuKi Notes is a capture app. You open it, type a thought (a QuKi), and close it. There is no vault, no folder structure, no organization ritual. When a QuKi needs to go somewhere, there's a Send action — clipboard, share sheet, or any transport you enable. 

## Platforms

Available on Android, Windows, and Linux. iOS and macOS are not yet available.

## Installation

Download the latest release from [GitHub Releases](https://github.com/ScottKirvan/QuKi-Notes/releases).

- **Android**: install the `.apk` directly, or sideload via ADB.
- **Windows**: extract and run the bundled `.exe`.
- **Linux**: extract and run the bundled binary.

## First launch

On first launch you will see a one-time setup screen asking where to store your QuKis:

- **Filesystem storage** — QuKis are stored in an accessible location on your device (a folder you pick on desktop; `Documents/QuKi_Notes` on Android). Files are visible in your file manager and survive uninstall. Recommended.
- **App storage** — QuKis are stored in the app's private directory. Files are not accessible via file manager and are deleted on uninstall. A warning is shown in Settings when this is active.

This screen appears once. You can change the location later in **Settings → Storage**.

After choosing, the editor opens — blank, cursor ready. Start typing.

Your QuKi saves automatically as you type. When you are done, send it somewhere or leave it — it will be in your QuKis list when you return.

## Navigation at a glance

The editor is home. It does not have a back button.

In the editor top bar:

- **QuKis icon** (top left) — opens your QuKis list
- **Type icon** — switch between live-preview and plain-text mode
- **+ icon** — start a new QuKi
- **Menu** (three-line icon, top right) — Send..., QuKis, Settings
