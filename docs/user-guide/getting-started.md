# Getting Started

## What is QuKi Notes?

QuKi Notes is a capture app. You open it, type a thought (a QuKi), and close it. There is no vault, no folder structure, no organization ritual. When a QuKi needs to go somewhere, there's a Send action — clipboard, share sheet, or any transport you enable. 

## Platforms

Available on Android, Windows, and Linux. iOS and macOS are not yet available.

## Installation

Download the latest release from [GitHub Releases](https://github.com/ScottKirvan/QuKi-Notes/releases).

- **Android**: install the `.apk` directly, or sideload via ADB.
- **Windows**: extract and run the bundled `.exe`.
- **Linux**: extract and run the bundled binary.

## First launch

The app opens directly into the editor — blank, cursor ready. No onboarding, no sign-in. Start typing.

Your QuKi saves automatically as you type. When you are done, send it somewhere or leave it — it will be in your QuKi list when you return.

## Navigation at a glance

The editor is home. It does not have a back button.

- **QuKis icon** (top left in the editor) — opens your QuKis list
- **Menu** (top right, three-line icon) — Send..., QuKis, Settings

From the QuKis list:

- **+ icon** (top right) — new QuKi
- **Settings icon** (top right) — Settings
