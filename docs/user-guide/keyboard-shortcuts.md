# Keyboard Shortcuts

QuKi Notes has no app-wide shortcuts of its own, such as for New or Send. The shortcuts below all work in the editor on every platform with a keyboard. On a Mac keyboard, use **Cmd** where this page says **Ctrl**.

## Editing

| Shortcut | Action |
|---|---|
| Tab | Indent the current or selected lines (see [Indenting](/user-guide/capturing-qukis#indenting)) |
| Shift+Tab | Dedent the current or selected lines |
| Enter | New line. In a list, task list or quote, continues it; on an empty item, ends it. |
| Backspace | Right after a list or quote marker, removes the marker |
| Ctrl+Z | Undo |
| Ctrl+Y (also Ctrl+Shift+Z on Linux; Cmd+Shift+Z on a Mac) | Redo |
| Ctrl+A | Select all |

Because Tab and Shift+Tab indent and dedent, neither moves keyboard focus out of the editor. Use the mouse or touch to reach the top-bar buttons from the editor.

## QuKis list and Trash

| Shortcut | Action |
|---|---|
| Tab | Move between rows and buttons |
| Enter or Space | Open the focused QuKi (in Trash: restore it) |

## Dialogs

| Shortcut | Action |
|---|---|
| Escape | Close the Help dialog |
